음악 이론 & 기술 원리
// BPM & TEMPO

BPM(Beats Per Minute)은 1분에 박자가 몇 번 반복되는지를 나타내. 힙합은 보통 80~100 BPM, 하우스는 120~130 BPM이야. 이 앱은 AI가 소리 특성을 보고 최적 BPM을 결정해.

beat_interval = 60000 / BPM (ms)
// FFT 주파수 분석

Fast Fourier Transform(FFT)은 소리를 주파수 성분으로 분해해. 저주파(킥 드럼)는 40-100Hz, 중주파(스네어)는 200-400Hz, 고주파(하이햇)는 8-16kHz 영역에 에너지가 집중돼.

f(t) → F(ω) = ∫ f(t)e^(-iωt)dt
// RMS 에너지 & 피크

RMS(Root Mean Square)는 오디오 신호의 실효 에너지를 측정해. 0.5초 슬라이딩 윈도우로 RMS가 가장 높은 구간이 '가장 강렬한 부분'으로 추출돼.

RMS = √(Σ x²ᵢ / N)
// 비트 시퀀서

드럼 머신처럼 16스텝(한 마디)의 격자에 소리를 배치해. 4분음표(4beat), 8분음표(8beat), 16분음표(16beat)로 세분화되고 각 소리가 맡을 역할을 AI가 결정해.

[K][_][S][_][K][_][S][HH]
// 다중감각 동기화

청각과 시각이 동시에 자극될 때 뇌는 더 강한 몰입감(Multisensory Integration)을 경험해. 80ms 이내의 AV 싱크가 유지되면 인간은 소리와 영상을 '같은 이벤트'로 인식해.

|t_audio - t_video| ≤ 80ms
