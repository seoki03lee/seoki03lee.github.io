일상속의 노래 v3 — 8채널 샘플러 워크스테이션

소리를 샘플링하고 AI가 8채널 합주 악보를 생성합니다.
여러가지 스타일의 음악을 만들어보세요.

01
Gemini API 키 준비

aistudio.google.com에서 API 키를 발급받으세요.

02
채널 추가 & 샘플 등록

처음엔 CH0 하나만 있어요. [+ 채널 추가] 버튼으로 최대 8개까지 늘릴 수 있습니다. 🎤 REC로 녹음하거나 📁 파일로 업로드하세요. 악기명에 "보이스"가 들어가면 피크 클립 없이 원본 전체를 사용합니다.

03
장르 / 분위기 설정

프리셋 버튼을 고르거나 직접 텍스트를 입력해 원하는 음악 스타일을 지정하세요. Gemini가 분위기를 반영해 작곡합니다.

04
음악 생성 & 제어

🎵 생성 버튼을 누르면 8마디 악보가 만들어집니다. 볼륨·피치 슬라이더로 채널을 조절하고, BPM 슬라이더로 속도를 바꾸고, WAV로 다운로드까지 할 수 있어요.

💡 v3 신기능 — 채널별 볼륨/피치 슬라이더 · BPM 실시간 조절 · 장르 직접입력 · 샘플 미리듣기 · WAV 다운로드 · 생성 히스토리(최근 5개) · 루프 카운터 · 보이스 채널 원본 재생
