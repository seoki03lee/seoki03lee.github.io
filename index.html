일상속에 비트로 🌿

비트의 베이스가 될 일상의 소리들을 채워줘!

비트에 맞춰 재생될 3초 영상을 찍어봐! (5개)

사용 방법 ⸜(*ˊᗜˋ*)⸝

1. 소리 모드에서 비트 재료가 될 소리 5개를 녹음해.

2. 영상 모드에서 각 소리에 어울리는 3초 영상을 촬영해!

3. Gemini API 키를 입력하고 버튼을 누르면, 네가 찍은 영상 5개가 비트에 맞춰 환상적으로 재생될 거야!

일상속의 비트 이야기

우리는 시각과 청각을 동시에 자극할 때 더 큰 몰입감을 느껴! 네가 찍은 3초 영상들이 비트의 박자(4분 음표, 8분 음표 등)에 맞춰 화면 여기저기서 튀어나올 거야.
