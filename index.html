일상속의 소리로 비트를 만들어보세요

주변의 소리를 녹음하면 AI가 분석해서 자동으로 비트를 만들어드려요.
영상도 함께 찍으면 비트에 맞춰 자동 편집됩니다.

01
Gemini API 키 준비

aistudio.google.com에서 무료로 API 키를 발급받으세요. 로그인 후 "Get API Key" 버튼을 클릭하면 됩니다.

02
소리 녹음 (1~5개)

🎵 비트 메이커 탭으로 이동해서 REC 버튼을 눌러 3초간 소리를 녹음하세요. 손뼉, 발소리, 컵 두드리기 등 주변의 어떤 소리든 OK!

03
영상 촬영 (선택사항)

각 소리에 어울리는 짧은 영상을 찍어두면, 비트가 재생될 때 영상이 함께 나옵니다. 안 찍어도 괜찮아요!

04
API 키 입력 후 비트 생성!

API 키를 입력하고 "비트 생성 및 재생 시작" 버튼을 누르세요. AI가 소리를 분석하고 자동으로 비트 패턴을 만들어 재생합니다.

💡 팁 — 킥 드럼 느낌의 묵직한 소리, 스네어 느낌의 탁 소리, 하이햇 느낌의 딱 소리를 각각 녹음하면 더 풍부한 비트가 만들어집니다! 마이크와 카메라 권한 허용이 필요합니다.

만든 목적

🌍

일상 속 소리의 재발견

우리 주변에는 수많은 소리가 있습니다. 책상을 두드리는 소리, 발걸음 소리, 빗소리... 이 앱은 그 평범한 소리들이 사실 훌륭한 악기가 될 수 있다는 것을 체험하게 해줍니다.

🤖

AI와 함께하는 창작

Google의 Gemini AI가 녹음된 소리를 분석해 어떤 악기 역할에 어울리는지 파악하고, 최적의 비트 패턴을 자동 설계합니다. 음악 지식 없이도 누구나 비트 메이커가 될 수 있습니다.

🎬

소리와 영상의 융합

단순히 소리를 재생하는 것에서 나아가, 직접 찍은 영상이 비트에 맞춰 자동 편집되는 경험을 제공합니다. 나만의 뮤직비디오를 즉석에서 만드는 것과 같은 즐거움을 줍니다.

✨

창의적 표현의 문턱 낮추기

악기를 다룰 줄 몰라도, 음악 이론을 몰라도 괜찮습니다. 스마트폰 하나와 주변의 소리만 있으면 자신만의 음악을 만들 수 있다는 것을 보여주고 싶었습니다.

01. SOUND CAPTURE

3초간 주변의 소리를 녹음하세요. Gemini가 악기 성격을 분석합니다.

02. VIDEO SYNC

소리에 어울리는 영상을 찍으세요. 비트에 맞춰 자동 편집됩니다.
