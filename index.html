일상속에 비트로 🌿

5가지 소리를 모두 채워줘! (´｡• ᵕ •｡`) ♡

반가워! 사용 방법 알려줄게! ⸜(*ˊᗜˋ*)⸝

  1. 주변의 재미있는 소리(박수, 컵 두드리기, 펜 소리 등)를 찾아봐!
  2. 5개의 슬롯에 각각 3초씩 소리를 녹음해줘.
  3. Gemini API 키를 넣고 '비트 생성' 버튼을 눌러!
  4. Gemini가 소리를 악기로 변환해서 멋진 비트를 만들어줄 거야!

* 소리가 재생될 때 예쁜 비주얼라이저를 감상해봐!

프로젝트: 일상속에 비트로

이 사이트는 무심코 지나치는 일상의 소음 속에 숨겨진 리듬을 찾아내는 마법 같은 공간이야. ( ◡‿◡ *)

노래가 된 일상의 사례들

  • 빗소리: 일정한 간격의 하이햇(Hi-hat) 비트로 변신!
  • 커피잔 부딪히는 소리: 맑은 트라이앵글이나 벨 소리!
  • 문 닫는 소리: 묵직한 킥 드럼(Kick Drum)!
  • 종이 구기는 소리: 찰진 스네어(Snare)나 쉐이커!

사용 기술

Gemini 1.5 Flash API가 사용자가 입력한 오디오의 파형과 주파수를 분석해서 가장 어울리는 악기를 매칭하고 비트를 구성해.
